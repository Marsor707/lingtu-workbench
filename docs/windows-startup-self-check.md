# Windows 启动问题自查（给反馈用户的操作清单）

适用现象：双击 `灵图工作台.exe` 后，托盘提示「正在启动本地服务」，浏览器一直没有打开页面，重启电脑也没有改善。

> 目标：30 秒内拿到「本地服务到底报了什么错」。1.0.10 起托盘右键菜单里有「状态」「打开日志目录」「打开数据目录」三项，可以直接跳过前两步。

## 第 1 步：看托盘菜单的真实状态（1.0.10 起）

右键托盘图标，看第一项「状态」：

| 显示 | 含义 | 下一步 |
| --- | --- | --- |
| `状态：正在启动本地服务` | 服务进程已拉起，还没回报就绪 | 等 30 秒；仍在启动中→第 1.1 步 |
| `状态：本地服务未就绪 · 本地服务进程意外退出（退出码 N）` | 服务进程崩了 | 第 2 步 |
| `状态：本地服务未就绪 · 20 秒内没有输出就绪信息` | 进程活着但卡住 | 第 2 步 |
| `状态：本地服务未就绪 · 端口 8765 未被释放` | 端口被别的进程占着 | 第 3 步 |
| `状态：检测到旧版本服务在运行（vX.Y.Z）` | 有旧版残留进程 | 点「重启本地服务」 |

菜单里同时有「打开日志目录」，点开以后把 `launcher.log` 发给我们即可。

### 1.1 手工启动本地服务（最关键的一步）

1. 右键托盘图标 →「退出」，确保后台没有残留进程。
2. 在安装目录（默认 `%LOCALAPPDATA%\灵图工作台`，或用户自选的文件夹）空白处 `Shift + 右键` →「在此处打开 PowerShell 窗口」。
3. 执行：

```powershell
.\lingtu-server.exe
```

4. 把窗口里的输出**整段截图或复制**给我们。正常情况会打印一行 `{"ready":true,"port":8765,...}`；失败时会直接打印 Node 的报错（例如数据库打不开、端口被占、文件被安全软件拦截）。

## 第 2 步：确认安全软件没有拦掉服务程序

管理员 PowerShell 执行：

```powershell
Get-MpThreatDetection | Select-Object -Last 5
```

如果看到 `lingtu-server.exe` 被隔离或删除的记录，请在 Windows 安全的「病毒和威胁防护 → 保护历史记录」里恢复并加入排除项，然后重装一次。

## 第 3 步：确认 8765 端口被谁占用

```powershell
netstat -ano | findstr :8765
```

拿到最后一列的 PID 后：

```powershell
Get-Process -Id <PID> | Select-Object Id,ProcessName,Path
```

如果占用者不是 `lingtu-server`，把进程名和路径发给我们——本地服务会回退到随机端口，托盘状态会显示真实端口。

## 第 4 步：回传这些文件

1. 托盘右键 →「打开日志目录」→ `launcher.log`
2. 托盘右键 →「打开数据目录」→ `workspace\logs\execution.log`
3. 第 1.1 步手工启动的控制台输出
4. 系统版本（`winver` 截图）

有了这四样，基本可以定位到具体环节；缺少日志时只能靠猜。
