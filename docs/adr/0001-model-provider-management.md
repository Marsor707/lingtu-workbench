# ADR 0001：多模型供应商由本地服务统一管理

## 状态

已采用

## 背景

工作台原来只有一组 Provider 地址和密钥，无法在多个模型服务之间切换，也无法按供应商观察任务结果。前端本地状态还会让配置和任务归属受页面生命周期影响。

## 决策

- 供应商配置、启用状态和成功/失败统计持久化到 SQLite。
- 任务创建时保存供应商 ID 与地址快照，后续切换不影响已提交任务。
- 切换只由后端校验；存在 `running` 任务时返回冲突并拒绝变更。
- 启用供应商最多一个；首个迁移的旧配置自动成为“默认供应商”。
- 统计按任务最终状态累计，取消不计数。

## 结果

页面关闭或重启服务后，供应商配置、启用状态、任务归属和统计仍可恢复。前端只负责展示和发起操作，不能绕过后端的切换锁定。
