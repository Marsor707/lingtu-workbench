# ADR 0002：4K 放大采用后端本地像素重采样

## 状态

已采用

## 背景

业务需要把 1K/2K 结果放大到 4K，但不希望再次调用模型。放大任务必须在后端队列中执行，不能依赖浏览器页面保持打开。

## 决策

- 设置项默认关闭，使用 `pixelUpscale4K` 表示是否启用。
- 任务创建时快照该开关，避免排队期间修改设置改变既有任务行为。
- 后端在 Provider 结果落盘前执行 Lanczos3 像素重采样，保持实际图片比例，最长边目标为 3840 像素；不对已达到目标的图片缩小。
- PNG 和 JPEG 在本地解码、重采样并统一输出 PNG；无法识别或解码失败的结果保留原始字节并记录旁路告警，不让任务因放大失败而失败。
- 放大不调用 Provider，不计入 Provider 成功/失败统计。

## 结果

关闭页面不会中断放大；任务日志包含是否跳过、原始尺寸和目标尺寸。放大是确定性的像素处理，不改变 Provider 请求成本和模型调用次数。
