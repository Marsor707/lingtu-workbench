# ADR 0004：用独立视觉 LLM 为生图结果命名

## 状态

已采用

## 背景

生图结果原先使用任务 ID 和序号命名，批量处理时不便于人工检索。命名模型需要视觉输入能力，且不应影响生图任务的成功判定。

## 决策

- LLM 供应商独立于生图供应商管理，单独维护名称、服务地址、模型、密钥、启用状态及成功/失败统计。
- 工作区设置中的“LLM 图片命名”默认关闭；任务创建时快照开关和当前启用的 LLM 连接。
- 生图结果物化后调用 OpenAI 兼容 `chat/completions` 视觉接口，要求模型返回严格 JSON 图片名称。
- 命名成功时使用安全化后的名称作为 PNG 文件名；同名文件追加序号避免覆盖。
- LLM 调用失败、超时或返回非法名称时只记录日志并回退原有任务 ID 文件名，不改变生图任务状态。

## 结果

页面关闭或服务重启不影响已提交任务的命名配置。LLM 密钥只在本地配置表中保存，任务快照、接口响应和日志不包含密钥；LLM 统计与生图 Provider 统计互不干扰。
